
---

## ✨ Features  
- ✅ User login with username and PIN (hard-coded accounts)  
- ✅ Display of account balance, transaction history, deposits & withdrawals  
- ✅ Transfer money between accounts  
- ✅ Request loan (based on account criteria)  
- ✅ Close account (removes account data)  
- ✅ Auto logout after inactivity (e.g., 5 minutes)  

---

## 💻 Technologies Used  
- HTML5  
- CSS3  
- JavaScript (ES6+ features: array methods, dates, Intl API)  
- Browser DOM APIs  

---

## 🧪 How to Run Locally  
1. Clone the repository:  
    ```bash
    git clone https://github.com/vivekkumar2909/Bankist.git  
    ```  
2. Navigate into the project folder:  
    ```bash
    cd Bankist  
    ```  
3. Open `index.html` in your preferred browser.  
4. Use the sample login credentials (see “Test Accounts” below) to explore features.
